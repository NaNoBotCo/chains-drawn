# Chains, Drawn · โซ่ วาดให้ดู

ChainsAtlas and comparable cross-chain tech, as toys, in English and Thai.

`page.html` is the page body (also the private artifact https://claude.ai/artifact/PQccRTPtRTHmAHoTMYRacs).
`python3 tools/build.py` wraps it into `docs/index.html`; `tools/card.py` draws `docs/card.jpg`;
`tools/serve.py` serves `docs/` on port 8883.
